# Darkman-AI Micro Edition — Size Analysis

The client was intentionally reduced to platform Android widgets, Kotlin standard library support, OkHttp, and SQLite. No React Native, Expo, Compose, image frameworks, or native media libraries are included.

| Artifact | Measured size | Target/status |
| --- | ---: | --- |
| Release APK from sandbox validation | 179,120 bytes (about 175 KiB) | Below the 25 MB APK target |
| Final source/docs tree before cleanup | About 748 KiB excluding generated build and dependency directories | Well below the 50 MB package target |
| Native libraries | None | Pure Kotlin/Java bytecode is ABI-neutral and can run on ARMv7; Gradle pins `armeabi-v7a` for future native additions |

The APK measurement is from the unsigned release output generated by `assembleRelease`. Android Studio's signed release APK can differ slightly because of signing metadata. Debug output should not be used as the size benchmark because release-only R8 and resource shrinking are enabled.

The final uploaded package excludes the locally generated APK, Gradle caches, Android build intermediates, and `node_modules`. It includes the Gradle wrapper launcher and `package-lock.json` so the recipient can reproduce the build and cloud install.
